# Sidecars Studio — Mission 13A Phase 0
## Instagram Video Export Feasibility Audit (Watchers Gate)

Read in this order before any work:
1. WATCHERS_AUDIT_REACT_v1.md
2. PROJECT_STATE.json
3. HANDOFF.md

Mission:
Determine whether the current React Studio can produce Instagram-ready video exports from the browser. This is an audit and prototype mission only.

Rules:
- Do not redesign UI.
- Do not add placeholder export buttons.
- Do not mark Video Export as implemented unless a real file is produced.
- Do not commit or push unless explicitly instructed.

## Investigation Tasks

1. Canvas Capture
   - Verify Three.js canvas can be captured using `HTMLCanvasElement.captureStream()`.
   - Record browser compatibility.

2. MediaRecorder
   - Test supported MIME types.
   - Detect support for:
     - video/webm;codecs=vp9
     - video/webm;codecs=vp8
     - video/mp4
   - Record actual `MediaRecorder.isTypeSupported()` results.

3. Prototype Recording
   - Capture a 5-second animation from the existing Studio canvas.
   - Produce one downloadable video.

4. Performance Test
   - Measure achieved FPS.
   - Note dropped frames.
   - Test at:
     - 1080×1920
     - 1080×1350

5. Browser Matrix
   - Chrome
   - Edge
   - Android Chrome (if possible)

## Watchers Evidence Gate

The mission is considered complete only if all of the following exist:

- [ ] One downloadable video generated by the app.
- [ ] MIME support table from `MediaRecorder.isTypeSupported()`.
- [ ] Browser/version tested.
- [ ] Resolution tested (1080×1920 and/or 1080×1350).
- [ ] FPS achieved and dropped-frame observations.
- [ ] Output file size and duration.

If any item is missing, Video Export remains NOT IMPLEMENTED in WATCHERS_AUDIT_REACT_v1.md.

## Success Criteria

Video Export remains NOT IMPLEMENTED until this phase produces an actual downloadable video generated by the app.
