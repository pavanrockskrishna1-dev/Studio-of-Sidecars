# ☕🔥 Premium GLB Commercial Studio — Multi-Version (V1 · V2 · V3 · V4 · V5 · V6)

**One self-contained HTML file** — a studio for any GLB product: coffee bikes,
BBQ bikes, espresso machines, cups, pastries, anything. No installs, no internet
needed — every demo product, the whole 3D engine, the asset library and the
brand studio are baked inside.

## Open it

Double-click **`Premium_GLB_Commercial_Studio.html`** in Chrome / Edge / Firefox /
Safari. It opens in **Version 2 (Instagram Commercial)**, already lit and loaded
with the demo **BBQ bike**; a **coffee set** is one click away. Drop any of your
own product `.glb` onto the page (works with any GLB, any size — auto centred,
scaled and grounded).

Demo models are also saved separately (`demo-bbq-bike.glb`, `demo-coffee-set.glb`)
so you can load them like a normal file.

## 🎨 V6 · Brand Studio — one tap brands your scene & reels

Reusable **brand kits** that travel with the scene across every version:

  watermark text · intro & outro card copy · a **default background**.
- **Ready-made sample kits** ship installed: **Coffee Bike**, **BBQ Bike** and

  🗑 Delete for every kit. Everything auto-saves to this device.

  the brand watermark floats bottom-right over the live view, and the kit
  follows you — switch to V1/V2/V3/V4/V5 and it stays. Previewing a reel in
  V4 · Creator Studio plays with the brand already on.
- **Watermark is stamped into every photo you export** (📷 / 🖼️ 4K) — white,
  corner-aligned, with your logo + text.
- **Intro / outro cards** preview with one tap — full-screen styled cards built
  from the kit’s logo, colours and font (▶ Preview intro / ▶ Preview outro).

  as you pick.
- Tablet-friendly: big kit tiles (92 px on touch), large touch buttons, clean

## ✨ V6 · Creator Hub — projects · undo · presets · backup · export

The **Creator Hub** lives inside V6 (no new version needed) and puts six
one-tap tools at the top of the V6 panel:

- **📁 Project Manager** — one tap saves the *entire* project to this device:
  every product (.glb included), part edits, lighting + backdrop, camera
  framing, the active brand kit and your reel — with an automatic scene
  thumbnail. Cards support **Rename / Duplicate / Delete / Open**, project
  files can be exported/imported offline.
- **⟲ Undo / ⟳ Redo** — unlimited history for every editing action (products,
  parts, colours, materials, lighting, brand, reel). Big touch buttons in the
  V6 panel + round floating ⟲/⟳ buttons, and desktop **Ctrl/⌘+Z** /
  **Ctrl/⌘+Shift+Z** (or Ctrl+Y).
- **🗂 Preset Library** — save and re-apply **camera**, **lighting** and full
  **scene** presets; one tap applies, one tap deletes.
- **💾 Auto Backup** — the studio quietly snapshots your scene every few
  minutes. If the app closes unexpectedly, a **“♻️ Recover your last session?”**
  card offers the latest snapshot on the next open.
- **📦 Batch Export — Creator Pack** — one click downloads a ready-to-post /
  ready-to-render zip: **Instagram Reel 1080×1920 MP4**, **Story PNG + MP4**,
  **Post 1080×1080 PNG**, **Hero images** (Front · Side · Rear · Top · 45°),
  and a **Transparent PNG cut-out pack**. PNGs render right here; the MP4s ship
  as self-contained **Blender Python** files in the same pack (same pipeline as
  V3 · Blender Python, so the two always stay compatible) — Blender renders
  true 1080×1920 H.264 MP4 offline.
- **🪄 Quick Workflow** — five big touch cards, exactly: **Choose Project →
  Add Assets → Choose Scene → Build Reel → Export**. No timelines, no
  keyframes, no pro panels. Build a reel by tapping big shot tiles and play it
  with one button.

Everything is **100% offline** and auto-saves to the same device.

## 🐍 V3 · Blender Python (Instagram Quality)

The WebGL studio stays your **real-time editor**. The Blender version adds a
one-click batch render pipeline that runs entirely in your own Blender with
Cycles:

- **One-click “Render in Blender”** exports the CURRENT scene — every loaded
  GLB with its part transforms, materials and visibility, the current camera
  framing, the current lighting rig and stage look — and downloads a complete,
  self-contained package (`instagram_render.py` with the embedded GLB,
  `scene.glb`, `render_windows.bat` / `render_mac_linux.sh`, `README_RENDER.txt`).
- **Render vertical 1080×1920 PNG or MP4 with Cycles**: still frame from the
  current camera, or a 30 fps reel with Orbit 360° / Dolly / Crane / Handheld
  moves (3–12 s), samples 64–512, denoise on/off, light-power sliders.
- Runs headless or in Blender’s UI: `blender -b -P instagram_render.py`
  (Blender 3.4+, free at blender.org).
- Verified end-to-end: a generated package ran in real Blender 4.2 and produced
  valid 1080×1920-grade Cycles renders (PNG and MP4) whose framing matches the
  WebGL export (edge correlation 0.71).
