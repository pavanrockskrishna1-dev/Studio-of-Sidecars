# Studio of Sidecars — UI Direction · Concept Set 01

Pure visual concepts for approval. **No implementation, no HTML/CSS.**
Sidecar removed; products shown are placeholder showcase assets (AI-rendered studio shots)
to design the *application*, not the product.

Each concept exists as a high-fidelity artboard in two sizes:
`concept{L}_{tag}_desktop.png` (1440×900) and `concept{L}_{tag}_tablet.png` (Honor Pad 1194×834).
Source SVGs are kept in `exported/` as editable masters. Fonts cached in `fonts/`.
