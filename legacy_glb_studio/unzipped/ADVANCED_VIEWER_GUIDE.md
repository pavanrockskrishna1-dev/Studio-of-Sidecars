## 🚀 How to Use:

### **Step 1: Add Your Models**

1. **Click "Add GLB File"**
2. **Select one or more .glb files**
   - You can select multiple at once!
   - BBQ_Bike.glb, Coffee_Bike.glb, etc.
3. **Models appear in the scene**
4. **Models list shows on the left**

---

### **Step 2: Select a Model**

1. **Click on any model** in the list
2. **It highlights orange**
3. **Edit controls appear**
4. **Stats show "Selected: [Model Name]"**

---

### **Step 3: Change Color**

**Method 1 - Color Picker:**
```
1. Select a model
2. Click the color picker
3. Choose any color
4. Model updates instantly!
```

**Method 2 - Quick Presets:**
```
1. Select a model
2. Click a color preset button
   - 🔥 Orange
   - 🔴 Red
   - 🔵 Blue
   - 🟢 Green
   - 🟡 Yellow
   - 🟣 Purple
   - ⚪ White
   - ⚫ Black
3. Model changes immediately!
```

---

### **Step 4: Change Material**

1. **Select a model**
2. **Choose "Material Type" dropdown:**
   - 🎨 Standard - Normal look
   - ✨ Glossy - Shiny finish
   - 🔩 Metallic - Metal appearance
   - 💎 Chrome - Mirror/chrome
   - 🧴 Plastic - Plastic look
   - 💡 Glowing - Emissive glow
3. **Material applies instantly!**

**Advanced:**
- Adjust **Metalness** slider (0 = not metal, 1 = full metal)
- Adjust **Roughness** slider (0 = mirror, 1 = rough)

---

### **Step 5: Move & Transform**

**Position:**
- **X slider** - Move left/right
- **Y slider** - Move up/down
- **Z slider** - Move forward/back

**Scale:**
- Drag slider to resize
- 0.5x = Half size
- 1.0x = Normal
- 2.0x = Double size

**Rotation:**
- Rotate Y slider
- 0° to 360°
- Spin your model!

---

### **Step 6: Delete Models**

**Delete One:**
1. Select the model
2. Click "🗑️ Delete Selected Model"
3. Confirms and removes

**Delete All:**
1. Click "🗑️ Clear All Models"
2. Confirms
3. Clears entire scene

---

### **Step 7: Merge Models**

**When you have 2+ models:**
1. Position them how you want
2. Click "🔗 Merge All Models"
3. All combine into one!
4. Now you have a composite design!

**Great for:**
- BBQ Bike + accessories
- Coffee Bike + equipment
- Multiple parts → one product

## 🎨 Material Settings Explained:

### **Standard (Matte):**
- Metalness: 0
- Roughness: 0.5
- **Use for:** Normal product shots

### **Glossy:**
- Metalness: 0
- Roughness: 0.1
- **Use for:** Shiny paint, polished surfaces

### **Metallic:**
- Metalness: 1.0
- Roughness: 0.3
- **Use for:** Metal parts, industrial look

### **Chrome:**
- Metalness: 1.0
- Roughness: 0.05
- **Use for:** Mirror finish, premium look

### **Plastic:**
- Metalness: 0
- Roughness: 0.4
- **Use for:** Plastic components

### **Glowing:**
- Emissive: ON
- **Use for:** Dramatic effect, LED lights

## 🆘 Troubleshooting:

### **Model won't change color:**
- Make sure model is selected (orange highlight)
- Click the model in the list first
- Then change color

### **Can't select model:**
- Click on the model NAME in the list
- Not the delete or eye icons
- Should highlight orange when selected

### **Merge button not showing:**
- Need at least 2 models loaded
- Add more models to see merge option

### **Position sliders don't work:**
- Select a model first
- Sliders only work on selected model
