# ⚡ The EASIEST Way to Start - 3 Steps

## 🎯 Complete Beginner? Start Here!

### Step 1: Open "Command Prompt" (Windows) or "Terminal" (Mac)

**Windows:**
1. Click the Start button (Windows logo, bottom-left corner)
2. Type: **cmd**
3. Press Enter
4. A black window opens ✅

**Mac:**
1. Press **Command (⌘) + Space** on your keyboard
2. Type: **terminal**
3. Press Enter
4. A window opens ✅

---

### Step 2: Go to Your Project Folder

**Copy and paste this line** (change if your project is not on Desktop):

**Windows:**
```
cd Desktop\bbq-bike-3d-showcase
```

**Mac:**
```
cd Desktop/bbq-bike-3d-showcase
```

Press **Enter**

---

### Step 3: Run These Two Commands

**Copy and paste this line**, press Enter:
```
npm install
```

**Wait 1-2 minutes** (lots of text will appear - that's normal!)

When it finishes, **copy and paste this line**, press Enter:
```
npm run dev
```

---

## 🎉 That's It!

**Your browser opens automatically** showing the 3D viewer!

Now:
1. Click "Choose GLB File" button
2. Select your BBQ bike or coffee bike .glb file
3. Your bike appears in 3D!
4. Create content! 🚴🔥☕

---
