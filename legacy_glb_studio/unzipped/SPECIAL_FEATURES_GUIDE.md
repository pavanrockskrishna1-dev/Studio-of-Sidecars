```
1. Select a part
2. See "Position (Precise):" section
3. Type exact numbers:
   X: 2.5
   Y: 1.0
   Z: -1.5
4. Part moves to exact position!
```

**OR use arrow buttons:**

```
⬅️ ⬆️ ➡️
↙️ ⬇️ ↗️
```
