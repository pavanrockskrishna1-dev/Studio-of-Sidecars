## 🆘 Troubleshooting

### **File won't open:**
- Make sure it ends with `.html`
- Right-click → Open With → Choose browser (Chrome, Firefox, etc.)

### **Blank page:**
- Check your internet (first time only)
- Try a different browser
- Make sure file isn't corrupted

### **Model won't load:**
- Make sure it's a `.glb` or `.gltf` file
- File size under 100MB recommended
- Check file isn't corrupted

### **Slow performance:**
- Close other browser tabs
- Try smaller .glb file
- Use a different browser (Chrome usually fastest)
